# Zametki

Zametki is a web application for recording medical consultations, transcribing audio, and generating structured medical notes with the help of AI.

## Features

- Record and store audio in the browser
- Transcribe recorded audio using Whisper
- Generate structured medical notes using an LLM
- Copy the generated note for further editing

## Tech Stack

- Python
- FastAPI
- JavaScript
- HTML/CSS
- faster-whisper
- OpenRouter API
- IndexedDB

## Status

Personal MVP in development. Currently focused on testing audio recording, transcription, and AI-assisted note generation.

## Disclaimer

This tool is intended for experimentation and workflow assistance. Generated transcriptions and medical notes must be reviewed by a qualified medical professional before use.
